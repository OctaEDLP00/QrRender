API Uso en código

import QRCode from '@qr-render/web'

const qr = new QRCode('#qr', {
	text: 'https://example.com',
	width: 300, height: 300,
	colorDark: '#111827', colorLight: '#f8fafc',
	correctLevel: 2,       // QrErrorCorrectLevel.H
	margin: 10,            // px físicos
	quietZone: 4,          // módulos virtuales
	roundness: 0,          // 0..1
	pixelSize: 1,          // 0.5..1
})

qr.makeCode('https://otrotexto.example')
qr.clear()
 
import { QRCodeModel, QrErrorCorrectLevel } from '@qr-render/core'

const model = new QRCodeModel(4, QrErrorCorrectLevel.M)
model.addData('https://example.com')
model.make()

model.getModuleCount()  // tamaño de la matriz NxN
model.isDark(row, col)  // consume la matriz tu propio renderer

Motor agnóstico: tabla Reed-Solomon completa V1–40, masking y versiones automáticas. Todo renderer (CLI, Canvas, el tuyo) consume esta matriz.

Opciones de @qr-render/web

Opción Tipo Default Descripción
text string "" Texto a codificar
width / height number 256 Dimensiones del canvas
colorDark / colorLight string #000 / #fff Colores de módulos
correctLevel number 2 (H) M=0 · L=1 · H=2 · Q=3
margin number 10 Margen físico en px
quietZone number 4 Módulos virtuales de borde
roundness number 0 Redondeo de módulos (0..1)
pixelSize number 1 Escala del módulo respecto al tile

Arquitectura Monorepo multipaquete

⚙️ @qr-render/core

Motor agnóstico: matriz, masking y Reed-Solomon. Tabla RS completa V1–40, sin dependencias, sin DOM. La fuente única de verdad compartida antes duplicada.

packages/core

🖥️ @qr-render/web

Renderer HTML5 Canvas para el navegador. Build ESM (core externo) + IIFE autocontenida para <script> directo.

packages/web

⌨️ @qr-render/cli

Comando qr con ANSI 8-bit, versiones automáticas V1–40 y exportación cero-deps a PNG (zlib + CRC32 propio) y SVG.

packages/cli

Terminal El comando qr

# QR animado en tu terminal
qr "https://example.com"

# Nivel de corrección, quiet zone y escala
qr "Payment ABC123XYZ" -s 3 -l H -q 5
 
# La extensión decide el formato (.png por defecto). Cero dependencias.
qr "WIFI:S:MyNetwork;P:password;;" --output ./wifi.png -s 6
qr "qr-render" --output ./qr.png -s 6 --dark "#101828" --light "#ffffff"
 
# Vector escalable, ideal para print y web
qr "https://example.com/pay" --output ./pay-qr.svg -l H
qr "Etiqueta práctica" --output ./etiqueta.svg -s 4 -q 2
