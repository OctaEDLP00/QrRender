API Uso en código

import QRCode from '@qr-render/web'

const qr = new QRCode('#qr', {
	text: 'https://example.com',
	width: 300, height: 300,
	colorDark: '#111827', colorLight: '#f8fafc',
	correctLevel: 2,       // QrErrorCorrectLevel.H
	margin: 10,            // px físicos
	quietZone: 4,          // módulos virtuales
	roundness: 0,          // 0..1
	pixelSize: 1,          // 0.5..1
})

qr.makeCode('https://otrotexto.example')
qr.clear()
 
import { QRCodeModel, QrErrorCorrectLevel } from '@qr-render/core'

const model = new QRCodeModel(4, QrErrorCorrectLevel.M)
model.addData('https://example.com')
model.make()

model.getModuleCount()  // tamaño de la matriz NxN
model.isDark(row, col)  // consume la matriz tu propio renderer

Motor agnóstico: tabla Reed-Solomon completa V1–40, masking y versiones automáticas. Todo renderer (CLI, Canvas, el tuyo) consume esta matriz.

Opciones de @qr-render/web

Opción Tipo Default Descripción
text string "" Texto a codificar
width / height number 256 Dimensiones del canvas
colorDark / colorLight string #000 / #fff Colores de módulos
correctLevel number 2 (H) M=0 · L=1 · H=2 · Q=3
margin number 10 Margen físico en px
quietZone number 4 Módulos virtuales de borde
roundness number 0 Redondeo de módulos (0..1)
pixelSize number 1 Escala del módulo respecto al tile

Componentes Un QR, cuatro sabores

@qr-render/web también se publica como componentes listos para tu framework: la misma pipeline Canvas (SVG estático en Astro) y un vocabulario de props compartido. Instalá @qr-render/web una sola vez y traé el wrapper por subpath. 

<script type="module">
	// Auto-registra <qr-code> de forma idempotente,
	// usable desde HTML plano, Vue, React, Astro…
	import '@qr-render/web/element'
</script>

<qr-code
	value="https://example.com"
	size="256"
	level="H"
	fg-color="#111827"
	bg-color="#f8fafc"
	roundness="0.3">
</qr-code>

¿Otro nombre de tag? import { defineCustomElement } from '@qr-render/web/element' y llamalo con el tag que quieras (defineCustomElement('mini-qr') → <mini-qr value="…">). 

import { render } from 'preact'
import { QrCode } from '@qr-render/web/preact'

render(
	<QrCode
		value="https://example.com"
		size={256}
		level="H"
		fgColor="#111827"
		roundness={0.3}
	/>,
	document.getElementById('app')
)

Arquitectura Monorepo multipaquete

⚙️ @qr-render/core

Motor agnóstico: matriz, masking y Reed-Solomon. Tabla RS completa V1–40, sin dependencias, sin DOM. La fuente única de verdad compartida antes duplicada.

packages/core

🖥️ @qr-render/web

Renderer HTML5 Canvas para el navegador. Build ESM (core externo) + IIFE autocontenida para <script> directo. Wrappers por subpath para Preact, Svelte 5, Astro y un web component <qr-code>.

packages/web

⌨️ @qr-render/cli

Comando qr con ANSI 8-bit, versiones automáticas V1–40 y exportación cero-deps a PNG (zlib + CRC32 propio) y SVG.

packages/cli

Terminal El comando qr

# QR animado en tu terminal
qr "https://example.com"

# Nivel de corrección, quiet zone y escala
qr "Payment ABC123XYZ" -s 3 -l H -q 5
 
# Compone el string WIFI: por vos (SSID primero, escape ZXing
# de \ ; , : ") — un separador sin escapar trunca el campo y el
# móvil reporta "contraseña incorrecta" aunque el QR decodifique.
qr wifi --ssid MyNetwork -p 'Sup3r$ecret'

# Caracteres especiales sin dolor + SSID oculta
qr wifi --ssid 'Mi;Red:Especial' -p 'pa:ss,"word' --hidden

# Red abierta y export en un paso
qr wifi --ssid FreeWifi --type nopass -o guest.png -s 8
 
# Imagen real en la terminal: kitty/iTerm2/sixel con
# auto-detección y fallback a semi-bloques/ASCII.
# Sin --ink* el render es ANSI.
qr "https://example.com" --ink-picture -w 40 -h 40   # bytes PNG
qr "https://example.com" --ink -m 2                  # SVG rasterizado al vuelo

# -w/-h/-m solo valen con --ink/--ink-picture (error si no);
# --help ya no tiene alias corto: -h es la altura
 
# La extensión decide el formato (.png por defecto). Cero dependencias.
qr "qr-render" --output ./qr.png -s 6 --dark "#101828" --light "#ffffff"
 
# Vector escalable, ideal para print y web
qr "https://example.com/pay" --output ./pay-qr.svg -l H
qr "Etiqueta práctica" --output ./etiqueta.svg -s 4 -q 2
